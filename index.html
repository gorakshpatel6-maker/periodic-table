A Short History

The periodic table was built step-by-step as scientists discovered patterns in elements.

1789 — Lavoisier

Antoine Lavoisier listed known elements and grouped them broadly as metals, non-metals, gases and earths. This was an early attempt at systematic classification.

1829 — Döbereiner

Johann Döbereiner proposed triads: groups of three elements with similar properties and a relationship between their atomic masses.

1866 — Newlands

John Newlands proposed the Law of Octaves, observing that properties repeated roughly after every eighth element when arranged by atomic mass.

1869 — Mendeleev

Dmitri Mendeleev arranged elements mainly by atomic mass and similar chemical properties. He left gaps for elements that had not yet been discovered and predicted their properties.

1913 — Moseley

Henry Moseley showed that elements should be ordered by atomic number, not atomic mass. This provided the foundation of the modern arrangement.

Today — Modern Periodic Table

The modern table contains 118 elements, arranged in increasing atomic number in 7 periods and 18 groups.

Understanding the Modern Table

The key ideas you need to read the table confidently.

Modern Periodic Law

The physical and chemical properties of elements are periodic functions of their atomic numbers.

Periods

Horizontal rows are called periods. There are 7 periods. Elements in the same period have the same number of occupied electron shells.

Groups

Vertical columns are called groups. There are 18 groups. Elements in a group often show similar chemical properties.

Atomic Number

Atomic number is the number of protons in an atom. It is the main basis for the modern arrangement.
